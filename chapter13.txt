Розділ 13. Документування результатів проєкту

Документування результатів проєкту є одною з найважливіших частин розробки ІС.

Документація дозволяє зберігати інформацію про структуру системи, її функціональність та принципи роботи.

У процесі розробки інформаційної системи онлайн-магазину були створені такі документи:

- опис вимог до системи
- користувачі системи
- функціональні сценарії (User Stories)
- UML-діаграми
- модель даних системи
- опис архітектури системи

Також для збереження результатів роботи було використано систему контролю версій Git та платформу GitHub.

Git дозволяє відстежувати всі зміни у проєкті, а також зберігати історію редагування.

Репозиторій на GitHub містить усі файли, створені під час виконання практичних робіт, що дозволяє легко переглядати результати проєкту.

Таким чином, використання системи контролю версій та створення документації забезпечує зручне управління проєктом і збереження результатів роботи.
